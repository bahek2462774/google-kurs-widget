# google-kurs-widget

Небольшой десктоп-виджет для macOS (Electron), который показывает курсы валютных пар прямо на рабочем столе. Пары настраиваются, интервал обновления настраивается (по умолчанию 30 минут).

Подробная инструкция по установке со скриншотами: **[страница проекта](https://bahek2462774.github.io/google-kurs-widget/)**.

## Важно

- Источник курса — парсинг страницы выдачи Google (`google.com/search?q=USD+to+RUB`). Это **не официальный API** и нарушает Условия использования Google. Разметка Google может измениться в любой момент и сломать парсер; анонимные запросы могут упереться в cookie-стену/CAPTCHA. Никаких гарантий точности или доступности.
- Приложение не подписано Apple Developer ID (не распространяется через Mac App Store). При первом запуске собранного `.app` macOS Gatekeeper покажет предупреждение — открывать через правый клик → «Открыть».
- Виджет — плавающее окно поверх рабочего стола (frameless, always-on-top), а не системный WidgetKit-виджет, встроенный в Центр уведомлений.

## Требования

- [Node.js](https://nodejs.org/) 20+ (разрабатывалось на 24)
- macOS (Electron-приложение, тестировалось только на macOS)

## Запуск

```bash
git clone git@github.com:bahek2462774/google-kurs-widget.git
cd google-kurs-widget
npm install
npm start
```

## Настройка

Нажмите на шестерёнку (⚙) в правом верхнем углу виджета — откроется окно настроек:
- добавление/удаление валютных пар (например `USD` → `RUB`);
- интервал автообновления в минутах.

## Тесты

```bash
npm test           # юнит-тесты (парсер, стор) + e2e (Playwright + Electron)
npm run test:live  # ручная, редкая проверка против настоящего Google (не гонять часто)
```

## Сборка

```bash
npm run build       # dist/mac-arm64/*.app, без подписи, для локального использования
npm run build:dmg   # .dmg
```
